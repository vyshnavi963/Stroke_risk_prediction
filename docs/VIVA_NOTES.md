# Quick Viva Notes

**What is the project?** An academic prototype for stroke-outcome prediction on a public dataset, SHAP explanations, and general educational prevention recommendations.

**Why explainable AI?** To inspect which input features contribute to model outputs and make the model's behavior easier to discuss.

**What is SHAP?** SHapley Additive exPlanations, a method that attributes contributions to individual features for a particular model output.

**Why is accuracy insufficient?** The dataset is imbalanced; a model can predict the majority class and still miss most positive cases. Recall, precision, F1 and average precision add context.

**What is the recommendation system?** A rule-based function that selects general health-education messages from user-entered inputs.

**Is this medically validated?** No. It is a classroom prototype, not a diagnosis tool or clinical risk calculator.

**What are the limitations?** Class imbalance, potential data leakage in basic preprocessing, lack of external validation, population differences, and no clinical validation.
